1 Proje Genel Bakış ve Kapsamı

Ankara’da su yönetimi, nüfus artışı, kentleşme, iklimsel dalgalanmalar ve barajlara bağımlı içme-kullanma suyu sistemi nedeniyle giderek daha kritik hale gelmektedir. Bu projenin amacı, Ankara’daki su kullanım verilerini, barajlara gelen su miktarını, yağış verilerini ve güncel baraj doluluk durumunu birlikte inceleyerek önümüzdeki aylar için kısa dönemli bir baraj doluluk oranı tahmini oluşturmaktır.

Çalışmada cevap aranan temel sorular şunlardır:

  1. Ankara barajlarına gelen su miktarı yıllara ve aylara göre nasıl değişmektedir?
  2. Barajlara gelen su miktarında belirgin bir mevsimsellik var mıdır?
  3. Yağış miktarı ile barajlara gelen su miktarı arasında nasıl bir ilişki vardır?
  4. Ankara’da dağıtılan ve çekilen su miktarı yıllar içinde nasıl değişmiştir?
  5. Güncel baraj su hacmi ve tahmini aylık net su dengesi kullanılarak önümüzdeki aylar için baraj doluluk oranı nasıl değişebilir?

Bu çalışma kesin bir hidrolojik tahmin modeli değil, açık veri kaynaklarına dayanan keşifsel ve karar destek amaçlı kısa dönemli bir su dengesi analizidir.

2 Veri

Bu çalışmada aşağıdaki veri bileşenleri kullanılmıştır:

  1. Aylık barajlara gelen su miktarı: Ankara barajlarına yıllara ve aylara göre gelen su hacmini gösterir.
  2. Ankara yağış verileri: Günlük veya saatlik yağış miktarını milimetre cinsinden gösterir.
  3. Dağıtılan, çekilen ve kişi başı çekilen su miktarı: Ankara’da su kullanımının yıllar içindeki eğilimini gösterir.
  4. Güncel baraj doluluk verisi: ASKİ baraj sayfasından çekilen baraj bazlı toplam hacim, mevcut su miktarı ve doluluk oranı bilgisidir.
  5. Arıtılan içme ve kullanma suyu miktarı: 2023-2024 gerçekleşme, 2025-2026 performans programı/hedef değeri olarak kullanılmıştır.

2.1 Veri Kaynağı

Veriler ASKİ kaynaklarından, açık kamu verilerinden ve meteorolojik gözlem verilerinden derlenmiştir. Güncel baraj doluluk verisi ASKİ’nin baraj doluluk sayfasından R ortamında çekilmektedir:

https://www.aski.gov.tr/tr/baraj.aspx

Kullanılan yerel dosyalar data/ klasöründe tutulmalıdır.

Önerilen dosya yapısı:

proje.qmd
data/
  Aylik_Baraj_Su_Miktari.xlsx
  Ankara Yağış Verileri (2023-2026).xlsx
  DAGITILAN CEKILEN VE KIS BASI CEKILEN.xls
  ANKARA DAGITILAN SU MIKTARI.xls
  sular nereden geliyor.xls

Dosya adları farklıysa kod içindeki aday dosya adlarına ekleme yapılabilir.

2.2 Veri Hakkında Genel Bilgiler

Barajlara gelen su, çekilen su, dağıtılan su ve mevcut baraj su hacmi metreküp cinsindedir. Yağış verisi ise milimetre cinsindedir. Bu nedenle yağış doğrudan hacim olarak değil, barajlara gelen suyu açıklamaya yardımcı iklimsel bir değişken olarak kullanılmıştır.

Baraj doluluk tahmininde temel formül şu şekildedir:

[ Tahmini Mevcut Su_{t+1} = Güncel Mevcut Su_t + Net Su Dengesi_t ]

[ Net Su Dengesi_t = Tahmini Gelen Su_t - Tahmini Tüketim_t ]

[ Tahmini Doluluk Oranı_t = ]

2.3 Tercih Sebebi

Bu veri setleri Ankara’nın su yönetimini hem arz hem de talep tarafıyla inceleme olanağı sağlamaktadır. Barajlara gelen su miktarı arz tarafını, arıtılan ve dağıtılan su miktarı talep tarafını, yağış verisi ise iklimsel arka planı temsil etmektedir. Güncel baraj doluluk verisi ise net su dengesini doğrudan doluluk oranı tahminine dönüştürmek için kullanılmıştır.

hacim_sayi <- function(x) {
  if (is.numeric(x)) {
    return(as.numeric(x))
  }
  
  x <- as.character(x)
  x <- str_squish(x)
  x <- str_replace_all(x, "\\s", "")
  x <- str_replace_all(x, "\\.", "")
  x <- str_replace_all(x, ",", ".")
  as.numeric(x)
}

yuzde_sayi <- function(x) {
  if (is.numeric(x)) {
    return(as.numeric(x))
  }
  
  x <- as.character(x)
  x <- str_squish(x)
  x <- str_replace_all(x, "%", "")
  
  if_else(
    str_detect(x, ","),
    as.numeric(str_replace(str_replace_all(x, "\\.", ""), ",", ".")),
    as.numeric(x)
  )
}

aski_url <- "https://www.aski.gov.tr/tr/baraj.aspx"

aski_veri_cek <- function(url) {
  sayfa <- read_html(url, encoding = "UTF-8")
  tablolar <- html_table(sayfa, fill = TRUE)
  
  uygun_index <- which(
    map_lgl(
      tablolar,
      ~ any(str_detect(names(.x), "Baraj|Hacim|Yüzde|Miktar")) && ncol(.x) >= 4
    )
  )
  
  if (length(uygun_index) == 0) {
    uygun_index <- which(
      map_lgl(
        tablolar,
        ~ any(str_detect(as.character(.x[1, ]), "Baraj|Hacim|Yüzde|Miktar")) && ncol(.x) >= 4
      )
    )
  }
  
  if (length(uygun_index) == 0) {
    stop("ASKİ sayfasında baraj tablosu bulunamadı.")
  }
  
  tablo <- tablolar[[uygun_index[1]]]
  
  if (!any(str_detect(names(tablo), "Baraj|Hacim|Yüzde|Miktar"))) {
    names(tablo) <- as.character(tablo[1, ])
    tablo <- tablo[-1, ]
  }
  
  names(tablo) <- names(tablo) |>
    str_squish()
  
  baraj_col <- names(tablo)[str_detect(names(tablo), "Baraj")][1]
  hacim_col <- names(tablo)[str_detect(names(tablo), "Toplam|Hacim")][1]
  su_col <- names(tablo)[str_detect(names(tablo), "SU Miktarı|Su Miktarı|Miktarı")][1]
  yuzde_col <- names(tablo)[str_detect(names(tablo), "Yüzde|Yuzde|%")][1]
  
  if (any(is.na(c(baraj_col, hacim_col, su_col, yuzde_col)))) {
    stop("ASKİ baraj tablosunda gerekli sütunlar bulunamadı.")
  }
  
  tablo |>
    transmute(
      baraj_adi = as.character(.data[[baraj_col]]),
      toplam_hacim_m3 = hacim_sayi(.data[[hacim_col]]),
      mevcut_su_m3 = hacim_sayi(.data[[su_col]]),
      doluluk_yuzde = yuzde_sayi(.data[[yuzde_col]])
    ) |>
    filter(
      !is.na(baraj_adi),
      !is.na(toplam_hacim_m3),
      !is.na(mevcut_su_m3)
    )
}

Ankara'da su yönetimi, nüfus artışı, kentleşme, iklimsel dalgalanmalar ve barajlara bağımlı içme-kullanma suyu sistemi nedeniyle giderek daha kritik hale gelmektedir. # Veri

Bu çalışmada aşağıdaki veri bileşenleri kullanılmıştır:

1. **Aylık barajlara gelen su miktarı:** Ankara barajlarına yıllara ve aylara göre gelen su hacmini gösterir.
2. **Ankara yağış verileri:** Günlük veya saatlik yağış miktarını milimetre cinsinden gösterir.
3. **Dağıtılan, çekilen ve kişi başı çekilen su miktarı:** Ankara'da su kullanımının yıllar içindeki eğilimini gösterir.

5. **Arıtılan içme ve kullanma suyu miktarı:** 2023-2024 gerçekleşme, 2025-2026 performans programı/hedef değeri olarak kullanılmıştır.

## Veri Hakkında Genel Bilgiler

Barajlara gelen su, çekilen su, dağıtılan su ve mevcut baraj su hacmi metreküp cinsindedir. Yağış verisi ise milimetre cinsindedir. Bu nedenle yağış doğrudan hacim olarak değil, barajlara gelen suyu açıklamaya yardımcı iklimsel bir değişken olarak kullanılmıştır.

Baraj doluluk tahmininde temel formül şu şekildedir:

\[
Tahmini\ Mevcut\ Su_{t+1} = Güncel\ Mevcut\ Su_t + Net\ Su\ Dengesi_t
\]

\[
Net\ Su\ Dengesi_t = Tahmini\ Gelen\ Su_t - Tahmini\ Tüketim_t
\]

\[
Tahmini\ Doluluk\ Oranı_t = \frac{Tahmini\ Mevcut\ Su_t}{Toplam\ Baraj\ Kapasitesi} \times 100
\]

## Tercih Sebebi

Bu veri setleri Ankara'nın su yönetimini hem arz hem de talep tarafıyla inceleme olanağı sağlamaktadır. Barajlara gelen su miktarı arz tarafını, arıtılan ve dağıtılan su miktarı talep tarafını, yağış verisi ise iklimsel arka planı temsil etmektedir. Güncel baraj doluluk verisi ise net su dengesini doğrudan doluluk oranı tahminine dönüştürmek için kullanılmıştır.

  gun_sayisi = days_in_month(as.Date(paste(tahmin_yili, 1:12, "01", sep = "-"))) |> as.integer()
) |>
  mutate(
    yil = tahmin_yili,
    tahmini_tuketim_m3 = aritilan_2026_m3 * gun_sayisi / sum(gun_sayisi),
    tahmini_tuketim_milyon_m3 = tahmini_tuketim_m3 / 1e6
  )

# Haziran-Aralık için tahmin tablosu
tahmin_aylari <- tahmin_edilecek_aylar |>
  mutate(yil = tahmin_yili) |>
  left_join(
    aylik_mevsimsel_ortalama,
    by = "ay_no"
  ) |>
  left_join(
    tuketim_aylik_2026 |>
      select(ay_no, tahmini_tuketim_m3, tahmini_tuketim_milyon_m3),
    by = "ay_no"
  ) |>
  arrange(ay_no) |>
  mutate(
    net_su_dengesi_m3 = tahmini_gelen_su_m3 - tahmini_tuketim_m3,
    net_su_dengesi_milyon_m3 = net_su_dengesi_m3 / 1e6,
    kumulatif_net_su_dengesi_m3 = cumsum(replace_na(net_su_dengesi_m3, 0)),
    kumulatif_net_su_dengesi_milyon_m3 = kumulatif_net_su_dengesi_m3 / 1e6,
    tahmini_mevcut_su_m3 = guncel_mevcut_su_m3 + kumulatif_net_su_dengesi_m3,
    tahmini_mevcut_su_m3 = pmax(tahmini_mevcut_su_m3, 0),
    tahmini_doluluk_yuzde = tahmini_mevcut_su_m3 / toplam_kapasite_m3 * 100
  )

tahmin_aylari |>
  select(

    tahmini_gelen_su_milyon_m3,

    net_su_dengesi_milyon_m3,
